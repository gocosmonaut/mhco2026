# Security Policy

If you believe you have found a security vulnerability in this module,
please do **not** file a public issue in the module's issue queue.

Instead, follow the Drupal Security Team's coordinated disclosure
process:

- Email the Drupal Security Team at **security@drupal.org**
- Include the module name (`lscache`), a description of the
  vulnerability, reproduction steps, and any proof-of-concept code
- The Drupal Security Team will coordinate with the maintainer and
  issue an advisory once a fix is available

For more information, see the
[Drupal.org security policy](https://www.drupal.org/security-team/security-advisory-policy).
